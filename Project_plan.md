
# Restaurant Sales Data Pipeline 
## Project Overview

The restaurant sales data pipeline is an end to end data engineering project designed to transfrom the raw restaurant sales dataset into a clean and analytics ready dataset.  
The project is planned to be developed using python and pandas, starting from dataset ingestion to exporting a clean analytics/ml ready dataset.  The project is alspo planned to follow a structured development process using git and github , with daily progress tracked using commits and a changelog file.
#
## Problem Statement

The raw hotel reservation dataset might contain missing values, duplicate records, inconsistent categorical values and other data quality issues. These kind of issues can affect the reliaility of analysis and further development of machine learning applications.  
The project's main goal is to build a reusable pipelinethat can  handle data ingestion, validation, transformation and finally export the dataset that is suitable for analytics and machine learning.
